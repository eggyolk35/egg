# 周易卜卦 · 六十四卦

一个基于《周易》六十四卦的在线起卦与解读 Web 应用。采用传统「三枚铜钱」法起卦，
呈现本卦、变爻、变卦，并依朱熹《周易本义》断法给出参看指引，援引卦辞爻辞以助决断。

## 技术栈

- **Next.js 16** + **React 19**（前后端一体）
- **TypeScript**（类型安全）
- **Tailwind CSS v4**（界面样式）
- 思源宋体（Noto Serif SC），水墨 + 鎏金古典主题


## 起卦原理（三枚铜钱法）

每爻掷三枚铜钱，阳面记 3、阴面记 2，三枚之和定爻：

| 和 | 爻象 | 阴阳 | 是否变爻 |
|----|------|------|----------|
| 6  | 老阴 ⚏ | 阴 | 变 |
| 7  | 少阳 ⚊ | 阳 | 不变 |
| 8  | 少阴 ⚋ | 阴 | 不变 |
| 9  | 老阳 ⚌ | 阳 | 变 |

连掷六次，自下而上成「本卦」；将变爻阴阳互换得「变卦」。概率 6:7:8:9 ≈ 1:3:3:1，与传统相合。
